## Identification

- **Revision codes:** a03111 (1GB), b03111 (2GB), c03111 (4GB)
- **Release:** June 2019 (initial launch)
- **Known issues:** USB-C connector missing CC resistor — some USB-C PD chargers do not recognize the board
