## Identification

- **Revision codes:** b03114 (2GB), c03114 (4GB), d03114 (8GB)
- **Release:** 2020
- **Key changes from Rev 1.2:** VL805 USB controller EEPROM removed (firmware loaded by SoC bootloader instead)
