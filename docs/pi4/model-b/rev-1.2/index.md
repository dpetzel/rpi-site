## Identification

- **Revision codes:** b03112 (2GB), c03112 (4GB)
- **Release:** 2019
- **Key changes from Rev 1.1:** Extra resistor on USB-C connector to fix PD protocol compliance, power regulator upgrade for higher-RAM variants
