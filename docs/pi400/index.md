# Pi 400

Repair reference data for Raspberry Pi 400 boards.

The Pi 400 is a keyboard-integrated computer based on the BCM2711 SoC (same as Pi 4). It does not use a "Model A" / "Model B" designation — there is a single board design with a 4GB RAM configuration. Revisions reflect PCB-level hardware changes.
